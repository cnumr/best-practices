## Descripción

Recomendamos limitar el número de archivos CSS para no multiplicar las peticiones HTTP y simplificar el renderizado en el navegador. Utilice una hoja de estilos común para todos los elementos compartidos, sea cual sea la visualización, y un archivo por resolución de destino o media query.

Importante: es necesario integrar estos archivos directamente en el código HTML y no mediante directivas @import en los propios archivos CSS. Dividiendo de esta manera, el terminal del usuario elegirá lo que le corresponde y restará prioridad a la carga de los archivos que no necesita. Si fuera necesario, los archivos CSS para ciertos componentes pueden cargarse en función del contexto.

Sin embargo, procure no llevar esta lógica al extremo teniendo un solo archivo CSS: esto haría el caché del navegador menos eficaz y obligaría al navegador a ejecutar código CSS innecesario para la carga de una página.

## Ejemplo

```
<link rel='stylesheet' id='css-css' href='communs.css' type='text/css'
media='all' />
<link rel='stylesheet' id='css-xs-css' href='petits-ecrans.css' type='text/css'
media='(max-width: 959px)' />
<link rel='stylesheet' id='css-sm-css' href='tablettes.css' type='text/css'
media='(min-width: 768px)' />
<link rel='stylesheet' id='css-mdlg-css' href='grands-ecrans.css' media='(min-
width: 960px)' />
<link rel='stylesheet' id='css-print-css' href='print.css' type='text/css'
media='print' />
```
