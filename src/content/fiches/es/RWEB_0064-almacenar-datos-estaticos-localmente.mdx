## Descripción

Con el soporte generalizado en todos los navegadores de las bases de datos clave-valor (IndexDB, Web Storage), y de la puesta en caché vía la API Cache Storage, ahora es posible almacenar localmente datos estáticos estructurados.

El interés del almacenamiento local es doble. Por una parte, se evitan las idas y vueltas inútiles con el servidor, lo que ahorra recursos y tiempo de respuesta. Por otra parte, como los datos son locales, es más fácil y más rápido manipularlos directamente en el dispositivo del usuario.

La ganancia potencial es la reducción de la carga del servidor, por lo tanto del número de equipos necesarios (de su huella ambiental y económica), desde los servidores HTTP hasta los servidores de base de datos.

## Ejemplo

Por ejemplo, para almacenar el nombre del usuario puede utilizar la siguiente instrucción:

```javascript
localStorage.setItem('name', 'nom_utilisateur');
```

Basta luego con utilizar la línea siguiente para recuperarlo posteriormente:

```javascript
var myName = localStorage.getItem('name');
```
