## Descripción

Las principales redes sociales tales como Facebook, X (anteriormente Twitter), Pinterest, etc., proporcionan plug-ins para instalar en una página web para mostrar un botón «Compartir» o un contador de «Me gusta». Estas bibliotecas JavaScript son a menudo pesadas de descargar y generan muchas peticiones. Prefiera enlaces directos, en HTML, hacia las páginas de compartir. Se pueden generar estos enlaces a mano (ver abajo) o vía una herramienta como Share Link Generator ([https://www.sharelinkgenerator.com](https://www.sharelinkgenerator.com)). ¡Esta buena práctica no se limita a las redes sociales!

## Ejemplo

Se puede añadir un botón que abre una ventana emergente (pop-up) de compartir como lo hacen los botones oficiales, por ejemplo con el siguiente código:

```html
<button type = "button" onclick = "window. open('https://www.facebook.com/ Sharer/Sharer.php?u=XXXXX', ', 'menubar = no, toolbar = no, resizable = yes, scrollbars = yes, height = 500, width = 700')">
	Comparto esta página en Facebook
</button>
```
