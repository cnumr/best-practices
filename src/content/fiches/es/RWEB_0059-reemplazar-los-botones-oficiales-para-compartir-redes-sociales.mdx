## Descripción

Las principales redes sociales como Facebook, X (antes Twitter), Pinterest, etc., proporcionan plugins para instalar botones de "Compartir" o contadores de "Me gusta" en las páginas web. Estas bibliotecas JavaScript suelen ser pesadas de descargar y generan una gran cantidad de peticiones HTTP.

Prefiera el uso de enlaces directos en HTML hacia las páginas de compartir. Puede generar estos enlaces manualmente (ver ejemplo abajo) o mediante herramientas como Share Link Generator. ¡Esta buena práctica no se limita solo a las redes sociales!.

## Ejemplo

Se puede añadir un botón que abra una ventana emergente (pop-up) de compartir, tal como lo hacen los botones oficiales, con el siguiente código:

```html
<button type="button" onclick="window.open('https://www.facebook.com/sharer/sharer.php?u=XXXXX', '', 'menubar=no, toolbar=no, resizable=yes, scrollbars=yes, height=500, width=700')">
  Comparto esta página en Facebook
</button>
```

Para ir más lejos, consulte la página: [https://www.nuweb.fr/736](https://www.google.com/search?q=https://www.nuweb.fr/736).
