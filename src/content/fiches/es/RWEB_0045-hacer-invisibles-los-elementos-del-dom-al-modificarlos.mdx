## Descripción

Cuando un elemento del DOM (Document Object Model) debe ser modificado por varias propiedades, cada cambio de estilo o de contenido generará un repaint o un reflow. Por ello, generalmente es más eficiente:

* Hacer el elemento invisible (pasar la propiedad display a none) (1 reflow);
* Modificar todas las propiedades del elemento y volver a hacerlo visible (1 reflow).

Total: 2 reflows como máximo.

## Ejemplo

Se recomienda proceder de la siguiente manera:

```javascript
var elem = document.getElementById('foo');
elem.style.display = 'none'; // Genera 1 reflow

elem.style.width = '10em';
elem.style.height = 'auto';
// ... otros cambios ...

elem.style.display = 'block'; // Genera 1 reflow
```

En total, se requieren 2 reflows en lugar de los 6 o 7 posibles.
