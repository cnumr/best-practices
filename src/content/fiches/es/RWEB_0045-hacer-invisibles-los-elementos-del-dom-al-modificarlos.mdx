## Descripción

Cuando un elemento del DOM (Document Object Model) debe ser modificado por varias propiedades, cada cambio de estilo o de contenido generará un repaint o un reflow. Así pues, generalmente es más económico:

* hacer el elemento invisible (pasar la propiedad display a none) (1 reflow);
* modificar todas las propiedades del elemento y hacer el elemento nuevamente visible (1 reflow).

O sea, 2 reflow como máximo.

## Ejemplo

Proceder de la siguiente manera:

```javascript
var elem = document.getElementById('foo');
elem.style.display = 'none'; // Genera 1 reflow

elem.style.width = '10em';
elem.style.height = 'auto';
// ... otros cambios ...

elem.style.display = 'block'; // Genera 1 reflow
```

Al final, son necesarios 2 reflow en lugar de 6 o 7 potencialmente.
