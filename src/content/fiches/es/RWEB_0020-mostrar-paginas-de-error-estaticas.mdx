## Descripción

Las páginas de error (40x, 50x) deben ser lo más ligeras posible e incluso, idealmente, inexistentes.

Cuando el navegador solicita un recurso que no existe (imagen, hoja de estilos CSS, archivo JavaScript, etc.) o el servidor genera un error, la página resultante puede llegar a ser más pesada que el propio recurso solicitado.

Además, algunos CMS ejecutan su rutina de búsqueda de contenido en la base de datos para intentar encontrar el recurso. Por consiguiente, se ejecuta código de servidor, se realizan consultas a la base de datos y se genera dinámicamente la página HTML. Todo este proceso resulta en un desperdicio de ciclos de CPU, de memoria RAM y de ancho de banda.

## Ejemplo

Evitar las páginas 404 dinámicas, personalizadas en función del contenido de la URL. Optar por una página 404 estática.
