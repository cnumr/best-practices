## Descripción

El acceso al DOM vía JavaScript es un procedimiento pesado que consume muchos ciclos de procesador (CPU), más aún si la página tiene un DOM importante. Reduzca tanto como sea posible estos accesos.

Para ello, puede asignar el nodo en variables que reutilizará durante el ciclo de vida de la aplicación, lo que evita volver a recorrer el árbol en cada manipulación del documento.

Si la página tiene un DOM importante, puede ser sensato utilizar bibliotecas de tipo «Shadow DOM», que optimizan las modificaciones del árbol mediante un sistema de lotes (batch).

## Ejemplo

Para saber más, puede consultar el proyecto de Shadow DOM del W3C: [https://w3c.github.io/webcomponents/spec/shadow/](https://www.google.com/search?q=https://w3c.github.io/webcomponents/spec/shadow/)

Y las recomendaciones del W3C para reducir los accesos al DOM vía JavaScript: [https://www.w3.org/wiki/JavaScript\_best\_practices#Keep\_DOM\_access\_to\_a\_minimum](https://www.google.com/search?q=https://www.w3.org/wiki/JavaScript_best_practices%23Keep_DOM_access_to_a_minimum)
