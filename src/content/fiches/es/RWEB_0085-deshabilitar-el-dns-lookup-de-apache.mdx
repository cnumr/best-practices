## Descripción

Cada vez que un servidor web recibe una petición HTTP, registra esta información en un log, traduciendo la dirección IP en nombre de dominio. Esta conversión (DNS Lookup) constituye uno de los cuellos de botella de ciertos servidores HTTP (especialmente Apache). Desactivar el DNS Lookup permite evitar el consumo inútil de recursos del servidor y acelera el tiempo de carga de las páginas, mejorando la experiencia del usuario.

## Ejemplo

En un servidor Apache, edite el archivo de configuración (/etc/apache/httpd.conf o /etc/apache2/apache2.conf) y añada esta directiva:

```apacheconf
 HostnameLookups Off
```
