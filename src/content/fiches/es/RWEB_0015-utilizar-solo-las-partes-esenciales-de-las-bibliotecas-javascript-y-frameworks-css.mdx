## Descripción

Al responder a las necesidades más comunes, las bibliotecas JavaScript tales como jQuery y los frameworks CSS listos para usar (Bootstrap, Skeleton, Gumby, Foundation...) permiten desarrollar sitios rápidamente. Pero no todos se basan en una arquitectura modular, lo que obliga al internauta a descargar toda la biblioteca para utilizar solo un pequeño porcentaje de las funcionalidades.

Es preferible prescindir de estas bibliotecas o conservar solo las porciones realmente utilizadas. Utilizar un bundler (por ejemplo, Webpack) permite realizar fácilmente el tree shaking, es decir, eliminar el código muerto y, por lo tanto, no utilizado. También se puede estimar el peso de una biblioteca con el sitio [https://bundlephobia.com/](https://bundlephobia.com/), que le dará una idea del peso total de un archivo «package.json».

## Ejemplo

Ciertos frameworks como Tailwind CSS proponen bibliotecas aligeradas que solo contienen las porciones realmente utilizadas. Esto reduce el peso de los archivos descargados por el navegador y los recursos consumidos durante la ejecución. Por ejemplo, jQuery ofrece una versión «slim» que no incluye ciertas funcionalidades como las animaciones CSS y el soporte de intercambios de datos en AJAX. Esto permite ahorrar 17 KB para la versión 3.6.
