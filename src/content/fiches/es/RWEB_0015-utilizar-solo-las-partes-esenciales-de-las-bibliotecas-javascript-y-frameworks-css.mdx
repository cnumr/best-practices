## Descripción

Al responder a las necesidades más comunes, las bibliotecas JavaScript como jQuery y los frameworks CSS listos para usar (Bootstrap, Skeleton, Gumby, Foundation...) permiten desarrollar sitios rápidamente. Sin embargo, no todas estas herramientas se basan en una arquitectura modular, lo que obliga al usuario a descargar toda la biblioteca para utilizar solo un pequeño porcentaje de las funcionalidades.

Es preferible prescindir de estas bibliotecas o conservar solo las partes realmente utilizadas. Utilizar un bundler (por ejemplo, Webpack) permite realizar fácilmente el tree shaking, es decir, eliminar el código muerto y, por lo tanto, no utilizado. También se puede estimar el peso de una biblioteca con el sitio bundlephobia.com, que le dará una idea del peso total de un archivo «package.json».

## Ejemplo

Algunos frameworks como Tailwind CSS ofrecen versiones ligeras que solo contienen las partes realmente utilizadas. Esto reduce el peso de los archivos descargados por el navegador y los recursos consumidos durante la ejecución. Por ejemplo, jQuery ofrece una versión «slim» que no incluye ciertas funcionalidades como las animaciones CSS y el soporte para intercambio de datos AJAX. Esto permite ahorrar 17 KB en la versión 3.6.
