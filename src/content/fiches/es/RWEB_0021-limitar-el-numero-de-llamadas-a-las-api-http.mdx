## Descripción

Cuando un usuario visita una página web, el sitio puede recuperar contenido a través de API HTTP (servicios web). En este caso, cada visualización de página generará solicitudes HTTP a las diferentes API, a pesar de que el contenido probablemente será el mismo durante un cierto tiempo.

Como proveedor de API (servidor), puede establecer cuotas para incitar a los usuarios a definir una estrategia de caché de respuestas y evitar peticiones redundantes.

Como usuario de API (cliente), debe almacenar en caché los resultados obtenidos para poder volver a utilizarlos sin llamar continuamente a la API HTTP.

## Ejemplo

* Si recupera opiniones de clientes vía API, es posible limitar el número de consultas a una por día.
* Si recupera un feed de Twitter para mostrarlo en su sitio, se puede limitar el número de consultas a una por hora.
* Si muestra un dato en tiempo real en la página de inicio, puede configurar una caché de 2 segundos para evitar que miles de visitantes simultáneos generen miles de llamadas a la API en el mismo segundo.
* Como proveedor, si ofrece una API, puede establecer cuotas por usuario y por período de tiempo.
