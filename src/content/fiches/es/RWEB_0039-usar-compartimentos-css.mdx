## Descripción

El CSS Containment (o contención CSS) indica que un nodo y su contenido son, en la medida de lo posible, independientes del resto del árbol de la página.

En función del tipo de independencia (strict, content, size, layout, style y/o paint) de la propiedad contain, el navegador:

* recalcula el renderizado (las posiciones, el formato, las disposiciones y/o la visualización) solo para el nodo independiente, ahorrando así recalcular la totalidad del DOM de la página;
* no realiza el renderizado del contenido de los nodos independientes fuera de la zona visible.

## Ejemplos

* Una arquitectura DOM compleja cuyo contenido de nodos se modifica en un momento dado:

```css
article {
  contain: content;
}
```

* Un widget externo:

```css
.widget-name {
  contain: layout;
}
```
