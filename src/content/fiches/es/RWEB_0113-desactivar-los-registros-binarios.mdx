## Descripción

Los logs binarios, por ejemplo los de una base de datos como MySQL o MariaDB, pueden llegar a ser muy voluminosos, consumiendo ciclos CPU y generando entradas-salidas (I/O) en el disco duro, ya que cada petición de modificación/supresión está inscrita en el archivo de log. Así que si tiene la opción de desactivar estos registros, se ahorrará una gran cantidad de recursos.
Antes de desactivar, debe asegurarse de que no es necesaria una replicación de la base de datos y que la pérdida de datos desde la última copia de seguridad es aceptable.

## Ejemplo

Para MySQL, añadir la siguiente configuración:

```
skip-log-bin
```
