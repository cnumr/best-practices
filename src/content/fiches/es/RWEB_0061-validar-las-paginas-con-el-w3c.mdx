## Descripción

Un código HTML bien formado permite una mejor accesibilidad, un mejor posicionamiento (SEO) y, sobre todo, una mejora del rendimiento.

En caso contrario, el navegador debe corregir dinámicamente los elementos erróneos para poder mostrar la página lo mejor posible. Estas correcciones dinámicas consumen recursos inútilmente en cada carga de las páginas afectadas.

## Ejemplo

Utilice el validador del W3C (World Wide Web Consortium) para verificar que las páginas son válidas y que el código HTML está correctamente formado:

* [https://validator.w3.org](https://validator.w3.org)
* [https://validator.w3.org/nu/](https://validator.w3.org/nu/)(para filtrar los errores)
