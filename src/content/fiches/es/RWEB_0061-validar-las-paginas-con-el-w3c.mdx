## Descripción

Un código HTML bien formado permite una mejor accesibilidad, un mejor posicionamiento (SEO), pero sobre todo una mejora del rendimiento. En caso contrario, el navegador corregirá dinámicamente un cierto número de elementos para mostrar lo mejor posible las páginas que presentan problemas. Estas correcciones dinámicas consumen inútilmente recursos en cada carga de las páginas afectadas.

## Ejemplo

Utilizar el validador del W3C (World Wide Web Consortium) para verificar que las páginas son válidas y que el código HTML está correctamente formado: [https://validator.w3.org](https://validator.w3.org)o [https://validator.w3.org/nu/](https://validator.w3.org/nu/)para filtrar los errores.
