## Descripción

Las imágenes, hojas de estilo CSS y archivos JavaScript deben estar alojados en un dominio sin cookies. Esto evita que el navegador envíe una cookie en cada solicitud de recurso cuando es inútil. Esto se debe a que, aunque se transfiere en cada solicitud HTTP, la cookie es innecesaria para el contenido estático, ya que su función es mantener el estado entre el navegador del internauta y el servidor de aplicaciones gracias a los identificadores que contiene. Por lo tanto, es mejor almacenar este tipo de contenido en un nombre de dominio específico, por ejemplo https\://www\.google.com/search?q=static.midominio.com.

## Ejemplo

Los líderes de la web utilizan un dominio separado para servir los recursos estáticos que no requieren cookies. Por ejemplo, Yahoo! utiliza el dominio https\://www\.google.com/search?q=yimg.com, YouTube el dominio https\://www\.google.com/search?q=ytimg.com y Amazon el dominio https\://www\.google.com/search?q=images-amazon.com.
