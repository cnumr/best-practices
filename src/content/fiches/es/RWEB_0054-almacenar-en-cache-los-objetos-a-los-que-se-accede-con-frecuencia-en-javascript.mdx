## Descripción

El acceso al DOM (Document Object Model) es costoso en términos de recursos del procesador (ciclos de CPU). Así pues, cuando utilice varias veces el mismo elemento del DOM desde JavaScript, almacene su referencia en una variable con el fin de no recorrer de nuevo el DOM para este mismo elemento.

## Ejemplo

No escribir:

```javascript
document.getElementById('menu').property1 = 'foo';
document.getElementById('menu').property2 = 'bar';
```

Sino más bien:

```javascript
var menu = document.getElementById('menu');
menu.property1 = 'foo';
menu.property2 = 'bar';
```
