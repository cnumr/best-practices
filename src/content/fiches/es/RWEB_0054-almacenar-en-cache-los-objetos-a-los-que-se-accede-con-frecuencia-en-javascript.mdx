## Descripción

El acceso al DOM (Document Object Model) consume muchos recursos del procesador (ciclos de CPU). Por tanto, cuando necesite utilizar varias veces el mismo elemento del DOM desde JavaScript, almacene su referencia en una variable. De este modo, evitará recorrer el DOM repetidamente para buscar el mismo elemento.

## Ejemplo

Evite esto:

```javascript
document.getElementById('menu').property1 = 'foo';
document.getElementById('menu').property2 = 'bar';
```

En su lugar, utilice variables:

```javascript
var menu = document.getElementById('menu');
menu.property1 = 'foo';
menu.property2 = 'bar';
```
