## Descripción

El tiempo de carga de una página en el navegador está directamente correlacionado con el número de archivos que este debe descargar y con el peso unitario de cada archivo.

Para cada archivo, el navegador envía una petición HTTP GET al servidor. Espera su respuesta y descarga el recurso en cuanto esté disponible. Según el tipo de servidor web utilizado, cuanto mayor sea el número de peticiones por página, menos páginas podrá servir por servidor. Disminuir el número de peticiones por página es crucial para reducir la cantidad de servidores HTTP (o incluso servidores de aplicaciones y de bases de datos) necesarios para el funcionamiento del sitio y, por lo tanto, los impactos ambientales asociados.

## Ejemplo

Existen varias técnicas para reducir el número de peticiones:

* Concatenar archivos JS.
* Concatenar archivos CSS.
* Crear sprites o fuentes de iconos.
* Utilizar el lazyload (carga diferida) para las imágenes.
