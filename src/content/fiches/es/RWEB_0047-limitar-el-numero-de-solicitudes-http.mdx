## Descripción

El tiempo de carga de una página del lado del navegador está directamente correlacionado con el número de archivos que el navegador debe descargar, y con el peso unitario de cada archivo.

Para cada archivo, el navegador emite un GET HTTP hacia el servidor. Espera su respuesta y luego descarga el recurso tan pronto como está disponible. Según el tipo de servidor web que utilice, cuanto mayor sea el número de peticiones por página, menos páginas podrá servir por servidor. Disminuir el número de peticiones por página es crucial para reducir el número de servidores HTTP (o incluso servidores de aplicaciones y de bases de datos) necesarios para el funcionamiento del sitio, y por lo tanto los impactos ambientales asociados.

## Ejemplo

Existen varias técnicas para reducir el número de peticiones:

* Concatenar archivos JS;
* Concatenar archivos CSS;
* Crear sprites o fuentes de iconos para los iconos;
* Utilizar el lazyload (carga diferida) para las imágenes.
