## Descripción

Las cabeceras HTTP Expires y Cache-Control definen el tiempo durante el cual un navegador debe conservar un recurso en su caché. Por lo tanto, deben configurarse correctamente para las hojas de estilo CSS, los scripts JavaScript y las imágenes.

Idealmente, la vida útil de estos elementos debe ser lo más larga posible, para que el navegador no vuelva a solicitarlos al servidor. Esto ahorra peticiones HTTP, ancho de banda y ciclos de CPU en el servidor.

## Ejemplo

He aquí un ejemplo de configuración de las cabeceras Expires y Cache-Control para el servidor web Nginx:

```
location ~* ^.+\.(xml|ogg|ogv|svg|svgz|eot|otf|woff|mp4|ttf|css|rss|atom|js|jpg|jpeg|gif|png|ico|zip|tgz|gz|rar|bz2|doc|xls|exe|ppt|tar|mid|midi|wav|bmp|rtf|webp|avif|webm)$ {
    access_log off;
    log_not_found off;
    expires max;
}
```

(Nota: Si su servidor es Apache, deberá utilizar el módulo mod\_headers o mod\_expires).
