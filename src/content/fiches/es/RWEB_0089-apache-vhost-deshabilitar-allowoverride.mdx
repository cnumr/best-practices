## Descripción

Cuando la directiva AllowOverride está activada, el servidor HTTP Apache (a diferencia de Nginx) debe remontar toda la jerarquía de directorios para, tal vez, encontrar un archivo .htaccess que contenga reglas de anulación. Por lo tanto, es aconsejable desactivar, si es posible, esta directiva en la configuración de Apache.

## Ejemplo

En el archivo de configuración de su host Apache, añada:

```
AllowOverride none
```

Para profundizar más: [https://httpd.apache.org/docs/2.0/mod/core.html#allowoverride](https://www.google.com/search?q=https://httpd.apache.org/docs/2.0/mod/core.html%23allowoverride)
