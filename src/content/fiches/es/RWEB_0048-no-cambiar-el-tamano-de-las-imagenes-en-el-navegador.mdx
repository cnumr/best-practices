## Descripción

Idealmente, el tamaño de visualización de una imagen en el navegador debe ser lo más cercano posible al del archivo de imagen descargado.

En el marco de las integraciones modernas, con las imágenes responsivas, es necesario definir bien los atributos srcset o sources para que cada tipo de dispositivo utilice una versión de imagen adaptada al tamaño y a la resolución de su pantalla.

NB: los atributos height y width permiten generalmente definir la relación de aspecto (ratio) de visualización más pequeña, pero es sobre todo el CSS el que hoy en día determina los tamaños de visualización según los tamaños de las pantallas.

Compare el número de píxeles de la imagen cargada con el número de píxeles realmente mostrados. La herramienta yellowlab.tools puede ayudarle.

## Ejemplo

Una imagen de 350 × 300 píxeles codificada en PNG 24 pesa 41 KB. La misma imagen mostrada en miniatura a 70 × 60 píxeles sigue pesando 41 KB, ¡mientras que no debería superar los 3 KB!

Ejemplo de sintaxis responsiva:

HTML:

```html
<img id="monimage" src="image_3ko.png" width="70" height="60"
srcset="image_3ko.png 640w, image_41ko.png 1920w">
```

CSS:

```css
#monimage { width: 70px; height: 60px }
@media(min-width: 640px) {
    #monimage { width: 350px; height: 300px }
}
```
