## Descripción

Idealmente, el tamaño de visualización de una imagen en el navegador debe ser lo más cercano posible al tamaño del archivo descargado.

En las integraciones modernas con imágenes responsive, es fundamental definir correctamente los atributos srcset o sources. Esto garantiza que cada dispositivo utilice una versión de la imagen adaptada específicamente al tamaño y resolución de su pantalla.

Nota: Si bien los atributos height y width suelen definir la relación de aspecto (ratio) base, hoy en día es principalmente el CSS el que determina el tamaño de visualización según la pantalla.

Compare el número de píxeles de la imagen cargada con el número de píxeles realmente mostrados. La herramienta yellowlab.tools puede serle de utilidad.

## Ejemplo

Una imagen de 350 × 300 píxeles codificada en PNG 24 pesa 41 KB. La misma imagen mostrada como miniatura a 70 × 60 píxeles sigue pesando 41 KB, ¡cuando no debería superar los 3 KB!

Ejemplo de sintaxis responsive:

HTML:

```html
<img id="monimage" src="image_3ko.png" width="70" height="60"
srcset="image_3ko.png 640w, image_41ko.png 1920w">
```

CSS:

```css
#monimage { width: 70px; height: 60px }
@media(min-width: 640px) {
    #monimage { width: 350px; height: 300px }
}
```
