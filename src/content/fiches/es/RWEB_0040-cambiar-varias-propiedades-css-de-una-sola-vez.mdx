## Descripción

Para limitar el número de repaint/reflow (repintado/reflujo), se aconseja no modificar las propiedades una a una. Preferir la adición/eliminación de clases CSS, lo que permite modificar de una sola vez varias propiedades, generando tan solo un repaint/reflow (ver la buena práctica n° 45).

## Ejemplo

Preferir la escritura:

```html
<style>
	.in-error {
		color: red;
		font-weight: bold;
	}
</style>
<script>
	$el.bind('error', function () {
        $el.addClass('in-error');
    });
    $el.bind('running', function () {
        $el.removeClass('in-error');
    });
</script>
```
