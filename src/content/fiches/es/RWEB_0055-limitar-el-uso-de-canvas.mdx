## Descripción

El elemento HTML canvas está diseñado inicialmente para dibujar gráficos, realizar juegos o generar imágenes sobre la marcha (on the fly) vía APIs JavaScript. Como todo script, el uso de canvas consume muchos recursos de CPU/GPU, lo que se traduce en una sensación de lentitud en los terminales menos veloces, empujando al usuario a reemplazarlos.

Este impacto es más importante cuando el renderizado se realiza de manera repetitiva (efecto dinámico, animación). Se recomienda utilizar otros elementos HTML nativos cuando sea posible y, en su defecto, implementar optimizaciones para limitar las necesidades de recursos de máquina.

## Ejemplo

* Realizar los renderizados únicamente si es necesario.
* Con las animaciones, utilizar window\.requestAnimationFrame() en lugar de window\.setInterval().
* Limitar el uso de bibliotecas pesadas.
* Probar el rendimiento de renderizado.
