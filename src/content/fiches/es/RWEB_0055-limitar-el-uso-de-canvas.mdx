## Descripción

El elemento HTML canvas fue diseñado inicialmente para dibujar gráficos, crear juegos o generar imágenes dinámicamente (vía APIs JavaScript). Al igual que cualquier script, el uso de canvas consume muchos recursos de CPU/GPU, lo que se traduce en una sensación de lentitud en los dispositivos menos potentes, llevando al usuario a reemplazarlos por obsolescencia percibida.

Este impacto es mayor cuando el renderizado se realiza de manera repetitiva (efectos dinámicos, animaciones). Se recomienda utilizar otros elementos HTML nativos siempre que sea posible y, en su defecto, implementar optimizaciones para limitar el consumo de recursos del hardware.

## Ejemplo

* Realice los renderizados únicamente si es necesario.
* Para las animaciones, utilice window\.requestAnimationFrame() en lugar de window\.setInterval().
* Limite el uso de bibliotecas pesadas.
* Pruebe el rendimiento de renderizado.
