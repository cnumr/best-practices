## Descripción

Los sistemas de gestión de bases de datos están diseñados y optimizados para responder eficazmente al procesamiento de grandes cantidades de datos. En el caso de procesamientos con una lógica más o menos compleja, debería realizarlos lo más cerca posible del dato con el fin de:

* Limitar el ancho de banda debido a la transferencia de datos no procesados;
* Aprovechar las optimizaciones de la base de datos en la manipulación de datos;
* Aligerar los ciclos de CPU del lado del servidor backend o incluso frontend.

## Ejemplo

En el caso de consultas complejas con una cantidad importante de datos y el uso de un sistema de gestión de bases de datos relacionales (SGBDR), se aconseja utilizar procedimientos almacenados ya que:

* Un procedimiento almacenado ahorra al servidor la interpretación de la consulta, dado que está precompilada;
* Un procedimiento almacenado consume menos ancho de banda, puesto que hay menos información intercambiada entre el servidor y el cliente.

Todos los SGBDR recientes (SQL Server, MySQL, PostgreSQL, etc.) admiten los procedimientos almacenados.
