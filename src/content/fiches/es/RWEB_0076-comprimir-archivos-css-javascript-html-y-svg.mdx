## Descripción

Para limitar el uso del ancho de banda y mejorar los tiempos de carga, comprima los archivos de texto: CSS, JS, HTML y SVG. El algoritmo permite comprimir al vuelo los recursos antes de enviarlos a los clientes.

Más recientemente, Brotli se ha popularizado gracias a su mayor rendimiento y a que es compatible con todos los navegadores más comunes.

## Ejemplo

Para utilizar Brotli en Nginx, basta con añadir la siguiente configuración:

```
# for compressing responses on-the-fly
load_module modules/ngx_http_brotli_filter_module.so;
# for serving pre-compressed files
load_module modules/ngx_http_brotli_static_module.so;

http {
    server {
        brotli on;
        # ...
    }
}
```

[(Nota: Si utiliza Apache, deberá usar el filtro BROTLI\_COMPRESS con AddOutputFilterByType).](https://github.com/google/ngx_brotli)
