## Descripción

Modificar el DOM (Document Object Model) mientras se recorre puede provocar situaciones donde el bucle consuma una cantidad excesiva de recursos, especialmente ciclos de CPU.

De hecho, si se añaden elementos durante el recorrido, es posible generar un bucle infinito que consumirá gran cantidad de recursos. Por lo tanto, se desaconseja encarecidamente este tipo de modificación.

## Ejemplo

Evitar:

```javascript
<script>
	// Notación de jQuery
	$('a. extlink'). each(function(el) {
    	$(el). attr('rel','external nofollow');
	})
</script>
```

Preferir:

```javascript
<script>
	$(document).ready(function() {
        var itemsToUpdate = [];
	$('.a.extlink').each(function() {
		itemsToUpdate.push(this);
        });
	$(itemsToUpdate).attr('rel', 'external nofollow');
    });
</script>
```

Este método permite almacenar los elementos del DOM que se van a modificar en una variable temporal y, posteriormente, efectuar todas las modificaciones en una sola operación.
