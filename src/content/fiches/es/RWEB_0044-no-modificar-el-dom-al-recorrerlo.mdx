## Descripción

Modificar el DOM (Document Object Model) cuando se recorre puede engendrar situaciones donde el bucle se vuelve muy exigente en recursos, especialmente en ciclos de CPU. En efecto, si se añaden elementos al recorrerlo, es posible generar un bucle infinito que consumirá una gran cantidad de recursos. Este tipo de modificación está, por lo tanto, fuertemente desaconsejada.

## Ejemplo

Evitar:

```javascript
<script>
	// Notación de jQuery
	$('a. extlink'). each(function(el) {
    	$(el). attr('rel','external nofollow');
	})
</script>
```

Preferir:

```javascript
<script>
	$(document).ready(function() {
        var itemsToUpdate = [];
	$('.a.extlink').each(function() {
		itemsToUpdate.push(this);
        });
	$(itemsToUpdate).attr('rel', 'external nofollow');
    });
</script>
```

Este método permite almacenar los elementos del DOM a modificar en una variable temporal y luego efectuar las modificaciones en una sola operación.
