## Descripción

El protocolo HTTP Strict Transport Security (HSTS) permite indicar a cualquier navegador, mediante una cabecera de respuesta HTTP almacenada en caché, que el dominio debe ser contactado exclusivamente por HTTPS. Esto permite que las peticiones siguientes, emitidas hacia el mismo dominio, se realicen exclusivamente con el protocolo HTTPS, lo que evita múltiples redirecciones 301 (para forzar las llamadas en HTTPS).

No obstante, la primera llamada exige una respuesta (potencialmente no segura) HTTP con una cabecera STS. Para paliar este problema y obligar a los navegadores a contactar con la totalidad del dominio en HTTPS, es posible, además de activar el HSTS, registrarse en una lista estática actualizada en todos los navegadores recientes ([https://hstspreload.org](https://hstspreload.org)). El registro es rápido y afecta a la totalidad del dominio (subdominios incluidos).

## Ejemplo

Ejemplo de configuración para Nginx

```apacheconf
add_header Strict-Transport-Security 'max-age=63072000; includeSubDomains; preload; always'
```
