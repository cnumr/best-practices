## Descripción

La arquitectura modular aporta a menudo una mayor capacidad de escalabilidad, costes reducidos de mantenimiento correctivo y evolutivo, así como un código más eficiente. Si la cobertura funcional del sitio web o del servicio en línea puede llegar a evolucionar, es mejor implementar las funcionalidades básicas en un núcleo y completarlas según sea necesario mediante módulos. Estos últimos pueden agrupar funciones pertenecientes a un mismo dominio de negocio. Esto permite desarrollarlos independientemente de otros dominios de negocio, así como compartirlos con otras aplicaciones.

Este enfoque es válido en todos los niveles de granularidad, tanto para un desarrollo a medida como para la elección de un servidor HTTP o de un CMS.
