## Descripción

La delegación de eventos evita sobrecargar la memoria del navegador instanciando un solo escuchador (listener) para varios elementos del DOM.

El principio es el siguiente: en lugar de asignar un evento a varios elementos de la página, puede colocar un solo evento en un elemento padre de estos objetos. Es en este gestor de eventos donde se determinará el elemento disparador gracias a event.target.

Más información en: [https://fr.javascript.info/event-delegation](https://fr.javascript.info/event-delegation)

## Ejemplo

Ejemplo de script para resaltar una celda de tabla:

```javascript
<script type="text/javascript">
	let selectedTd;
	table.onclick = function(event) {
		let target = event.target;
	if (target.tagName != 'TD') return;
	highlight(target);
  };
	function highlight(td) {
    if (selectedTd) {
		selectedTd.classList.remove('highlight');
    }
	selectedTd = td;
	selectedTd.classList.add('highlight');
  }
</script>
```

Aquí no se agrega un evento en cada celda, sino únicamente en la tabla.
