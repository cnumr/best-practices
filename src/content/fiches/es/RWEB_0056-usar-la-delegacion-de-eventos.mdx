## Descripción

La delegación de eventos evita sobrecargar la memoria del navegador instanciando un único escuchador (listener) para múltiples elementos del DOM.

El funcionamiento es el siguiente: en lugar de asignar un evento a varios elementos de la página, se vincula un único evento a un elemento padre de estos objetos. Es dentro de este manejador de eventos donde se determinará el elemento desencadenante gracias a event.target.

Más información en: [https://es.javascript.info/event-delegation](https://es.javascript.info/event-delegation)

## Ejemplo

Ejemplo de script para resaltar una celda de tabla:

```javascript
<script type="text/javascript">
	let selectedTd;
	table.onclick = function(event) {
		let target = event.target; // dónde ocurrió el clic
	if (target.tagName != 'TD') return; // no es una celda? entonces no nos interesa
	highlight(target); // resaltarlo
  };

	function highlight(td) {
    if (selectedTd) {
		selectedTd.classList.remove('highlight');
    }
	selectedTd = td;
	selectedTd.classList.add('highlight');
  }
</script>
```

Aquí no se asocia un evento a cada celda, sino únicamente a la tabla (el padre).
