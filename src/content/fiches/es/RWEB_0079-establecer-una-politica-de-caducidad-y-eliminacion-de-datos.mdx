## Descripción

Definir una duración de retención para cada dato almacenado con el fin de permitir su eliminación o su archivado mediante un procesamiento (por lotes, tiempo de vida o «TTL» en base de datos...). Muchos SGBD permiten eliminar automática y definitivamente datos mediante un TTL (Time To Live) en una tabla o en un dato.

Además, desde la implementación del RGPD, es obligatorio eliminar los datos personales de un usuario después de una cierta duración, lo cual se alinea con el ecodiseño.

## Ejemplo

Aquí, en una base de datos Oracle en Java, el dato expira después de 5 días:

```java
String aKey = "myFirstKey";
String aData = "myFirstData";

try {
    DatabaseEntry theKey = new DatabaseEntry(aKey.getBytes("UTF-8"));
    DatabaseEntry theData = new DatabaseEntry(aData.getBytes("UTF-8"));

    WriteOptions wo = new WriteOptions();
    wo.setTTL(5); // TTL de 5 dias
    myDatabase.put(null,             // transacción 
                   theKey,           // clave.
                   theData,          // valor.
                   Put.NO_OVERWRITE, 
                   wo);              // Optiones (incluyendo el TTL).

} catch (Exception e) {
    // ...
} 
```
