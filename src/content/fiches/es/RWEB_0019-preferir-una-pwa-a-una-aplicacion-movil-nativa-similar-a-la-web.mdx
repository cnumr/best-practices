## Descripción

Durante el diseño de un servicio digital, es indispensable definir los soportes necesarios en función de los usuarios. Un sitio web responsivo puede ser totalmente suficiente y satisfactorio.

Sin embargo, si una aplicación móvil es estrictamente necesaria y replica total o parcialmente el sitio web, entonces una PWA (Progressive Web App) es una solución que evita los desarrollos y mantenimientos dobles, o incluso triples, que ocasionaría el desarrollo de una aplicación móvil nativa o híbrida (React Native, Flutter).

Al no estar vinculada a un sistema operativo (OS) y ser a menudo más ligera que una aplicación móvil nativa, la PWA permite reducir el riesgo de obsolescencia del terminal móvil y un menor uso del ancho de banda. Es así como varias redes sociales han desarrollado una PWA para conquistar el mercado africano.

## Ejemplo

* Sitios de comercio electrónico (Lancôme, Starbucks, etc.)
* Medios de comunicación (L'équipe, Courrier International, Forbes, etc.)
* Software como Servicio - SaaS (Microsoft 365, Gmail, etc.)
* Redes sociales (Twitter Lite, Telegram, etc.)
* Aplicaciones de negocio (SNCF, etc.
