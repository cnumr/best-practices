## Descripción

Si el servidor de aplicaciones o el CMS propone un sistema de caché multinivel, utilícelo. Su granularidad permite reducir los recursos consumidos (ciclos de CPU, memoria) y ofrecer un alto rendimiento al usuario, consumiendo a la vez menos recursos en el lado del servidor.

## Ejemplo

WordPress dispone de diferentes extensiones de gestión de caché: LiteSpeed Cache, WP Fastest Cache, W3 Total Cache o WP Super Cache.

Gracias a estos plugins, las páginas se almacenan en caché en el servidor y ya no se generan dinámicamente para cada usuario. Adicionalmente, este tipo de herramientas proporciona otras optimizaciones orientadas a la WebPerf que favorecen el ecodiseño web.

Es interesante también activar el almacenamiento en caché de las consultas SQL para reducir la carga de la base de datos.
