## Descripción

El uso de una herramienta de minificación para CSS, JavaScript, HTML y SVG permite eliminar espacios inútiles, comentarios de los desarrolladores, saltos de línea, delimitadores de bloques, etc., y así reducir el tamaño de los archivos.

## Ejemplo

Existen diferentes herramientas para minificar archivos; estas son algunas de ellas:

* CSS: cssnano, csso o clean-css
* JavaScript: Terser, UglifyJS o Babel-minify
* HTML: htmlnano, HTMLMinifier
* SVG: SVGO, minify-xml, SVGOMG o equivalente
