## Descripción

Si su página web contiene una o varias zonas de contenidos que requieren una alta tasa de actualización, le aconsejamos proceder a una recarga únicamente de estas y no de toda la página. Para ello puede emplear varias técnicas, generalmente Javascript, aunque también es posible recurrir a un Service Worker, un Web Component o un desarrollo a medida.

Incluso es posible no incluir estas partes en la llamada HTTP de la página para "hidratarla" con estas zonas dinámicas en Javascript, lo que algunos llaman "component islands" o "islands architecture" (arquitectura de islas). El interés radica en poder conservar una solución de caché para la página "contenedor" y recargar solo las "islas" de contenido que lo necesitan.

## Ejemplo

Los sitios de noticias utilizan muy a menudo este procedimiento, que permite identificar claramente las zonas que necesitan ser actualizadas rápidamente (noticias de última hora, datos meteorológicos, cotizaciones de bolsa, resultados deportivos, etc.).
