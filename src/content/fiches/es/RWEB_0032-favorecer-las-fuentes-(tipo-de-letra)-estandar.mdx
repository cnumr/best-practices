## Descripción

Prefiera las fuentes estándar, ya presentes en el ordenador del usuario. Están listadas en el sitio [systemfontstack.com](https://systemfontstack.com/), por ejemplo. Si añade una fuente particular para su servicio digital, incluso si es una API de fuentes (Google Fonts, Adobe Fonts, etc.), usted debe:

* alojar la fuente usted mismo;
* utilizar una falsa negrita mediante la propiedad CSS -webkit-text-stroke;
* preferir una fuente variable (variable font) si necesita más de una fuente;
* optimizar la fuente eliminando los caracteres innecesarios a través del sitio [glyphrstudio.com](https://www.glyphrstudio.com/).

Aquí la fuente Montserrat solo se descarga si el usuario no ha definido preferencia. Por el contrario, la fuente Arial se utilizará sin descarga de Montserrat.

```css
@media (prefers-reduced-data: no-preference) {
  @font-face {
    font-family: Montserrat;
    font-style: normal;
    font-weight: 400;
    src: url('fonts/montserrat-latin-regular.woff2');
  }
}

body {
  font-family: Montserrat, Arial;
}
```
