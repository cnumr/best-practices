## Descripción

Utilice propiedades CSS en lugar de imágenes. De hecho, el peso de una hoja de estilos es mucho menor, especialmente si está comprimida. Además, la llamada a una hoja de estilos genera una única petición HTTP, frente a un gran número si se emplean muchas imágenes (una petición HTTP por cada imagen).

## Ejemplo

Las esquinas redondeadas, los bordes decorados y los filtros visuales de los elementos deben gestionarse con CSS en lugar de usar imágenes.

Preferir la escritura:

```css
#cadre {
  border-radius: 10px;
}
```

```html
<div id="cadre">
	<p>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</p>
</div>
```
