## Descripción

El analizador de calidad de código JSLint verifica que la sintaxis JavaScript utilizada sea compatible con todos los navegadores. De este modo, el código resultante cumple con restricciones sintácticas que permiten a los intérpretes ejecutarlo con mayor facilidad y rapidez. En consecuencia, se reduce el tiempo de procesamiento.

En los desarrollos modernos, recomendamos incorporar diferentes herramientas de aseguramiento de calidad de código en su proceso de entrega.

## Ejemplo

Por ejemplo, se pueden utilizar:

* ESLint para el código JavaScript;
* Stylelint para sus hojas de estilo.
