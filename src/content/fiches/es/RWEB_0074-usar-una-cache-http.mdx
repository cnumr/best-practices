## Descripción

Los proxies inversos (Varnish, Squid o Nginx) están optimizados para servir contenido (páginas HTML, imágenes, etc.) de forma rápida, consumiendo el menor número posible de ciclos de CPU. Al evitar solicitar inútilmente al servidor de aplicaciones, permiten utilizar una infraestructura de hardware más reducida, lo que limita el impacto ambiental asociado.

## Ejemplo

El uso de un proxy inverso especializado como Varnish reduce drásticamente el tiempo necesario para servir las páginas dinámicas almacenadas en caché, aliviando al servidor de aplicaciones / CMS para que pueda atender nuevas peticiones (no cacheadas). También se constata que una caché generalista como APC no es adecuada para esta función.
