## Descripción

Emplear un conjunto de CSS en lugar de una sola, y llamar únicamente a las CSS útiles en función del contexto. Este método permite limitar el peso de la página durante la primera descarga, ahorrando así ancho de banda y reduciendo la carga de CPU.

## Ejemplo

Dividir las CSS en función de la lógica funcional:

* layout;
* content;
* módulo x;
* módulo y;
* etc...

En el caso de un sitio funcionalmente rico, esto permitirá excluir todas las CSS de los módulos no utilizados. El número de CSS debe mantenerse razonable, más por cuestiones de mantenibilidad que de rendimiento, en la medida en que las CSS generales («layout» y «content» en nuestro ejemplo) serán concatenadas en un solo archivo. Las CSS complementarias (aquí, «módulo x» y «módulo y») serán descargadas en función del contexto (página, funcionalidades...).
