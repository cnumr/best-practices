## Descripción

La combinación de hojas de estilo CSS y/o de bibliotecas JavaScript permite reducir el número de solicitudes HTTP.

## Ejemplos

En WordPress, los plugins gratuitos Autoptimize o Assets CleanUp permiten combinar de forma sencilla los archivos CSS. Con Webpack, el plugin webpack-merge-and-include-globally facilita la fusión de los archivos CSS y JavaScript.
