## Descripción

Cuando el navegador transforma el código en una página web, debe realizar varias tareas antes de poder mostrar la página: analizar el script HTML, construir la estructura y el contenido de la página web (DOM) y, finalmente, ejecutar su código CSS y JavaScript.

La ejecución del código JavaScript puede ocupar los procesadores del terminal (dispositivo) en más del 90 %, lo que bloquea los otros procesamientos, o incluso las interacciones con el usuario. Al solicitar fuertemente al terminal, esto induce un consumo excesivo que impacta directamente el ciclo de recarga de la batería y degrada la experiencia de usuario (sensación de lentitud). Estos dos aspectos pueden llevar a una renovación del terminal del usuario debido a una obsolescencia percibida.

Para evitar esto, divida sus códigos JavaScript en pequeñas tareas ejecutadas en el momento oportuno y no antes.

## Ejemplo

El Total Blocking Time (TBT) mide el tiempo total ocupado por las tareas largas (long tasks) durante la actividad principal del hilo (thread) de JavaScript. Una tarea larga es un procesamiento que dura más de 50 ms y que monopoliza el navegador web. Hay que asegurarse de que el TBT esté por debajo de los 200 ms. La medición se puede efectuar con LightHouse ([https://web.dev/measure/](https://web.dev/measure/)) o Web Page Test ([https://webpagetest.org/](https://webpagetest.org/)).
