## Descripción

Cuando el navegador procesa el código de una página web, debe realizar varias tareas antes de poder mostrarla: analizar el código HTML, construir la estructura y el contenido (DOM) y, finalmente, ejecutar el CSS y el JavaScript.

La ejecución del código JavaScript puede ocupar los procesadores del dispositivo en más del 90%, lo que bloquea otros procesos e incluso las interacciones con el usuario. Al exigir un uso intensivo al dispositivo, se induce un consumo excesivo que afecta directamente a la duración de la batería y degrada la experiencia de usuario (sensación de lentitud). Estos dos aspectos pueden llevar al usuario a renovar su dispositivo debido a una obsolescencia percibida.

Para evitar esto, divida su código JavaScript en pequeñas tareas que se ejecuten en el momento oportuno y no antes.

## Ejemplo

El Total Blocking Time (TBT) mide el tiempo total ocupado por las tareas largas (long tasks) durante la actividad del hilo principal (main thread) de JavaScript. Una tarea larga es un proceso que dura más de 50 ms y monopoliza el navegador. Hay que asegurarse de que el TBT esté por debajo de los 200 ms. La medición se puede efectuar con Lighthouse ([https://web.dev/measure/](https://web.dev/measure/)) o Web Page Test ([https://webpagetest.org/](https://webpagetest.org/)).
